# Shortcuts

All of these work in the **timing window**, when no text field has focus.

## Keyboard

| Key | Action |
|---|---|
| **Space** | Play / pause from the cursor |
| **Left / Right** | Previous / next grid line |
| **Up / Down** | Previous / next timing point |
| **A** | Add a timing point at the cursor |
| **Delete** | Delete the selected timing point (on the **Rhythm** tab: the selected rhythm point) |
| **T** | Tap tempo |
| **Ctrl+Z** | Undo |
| **Ctrl+Y** or **Ctrl+Shift+Z** | Redo |

## Mouse

| Action | Result |
|---|---|
| Click the waveform | Move the cursor (snaps to the grid, **Alt** = free) |
| Drag the waveform | Scroll |
| Drag a marker | Move a timing point or a rhythm point (**Shift** on a timing point = snap to the nearest hit) |
| Drag the overview strip | Jump anywhere in the song |
| Wheel | Next / previous grid line |
| **Shift** + wheel | Scroll |
| **Ctrl** + wheel | Zoom |

## Dropping files

Drop an **audio file** or a **`.osu` file** onto the game window. In the level editor this opens the timing window and loads the file.
